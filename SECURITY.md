# Security policy

## Reporting a vulnerability

This repository contains documentation, methodology artifacts, and a single Bash bootstrap helper. If you discover:

- a **secret, credential, or client-identifying information** accidentally committed to this repository,
- a **defect in `scripts/new-engagement.sh`** that could be used to escape the engagements directory or execute arbitrary commands, or
- **errata in a compliance overlay** that could lead a practitioner to give materially wrong advice to a client (mis-cited regulations, missing mandatory-from dates, etc.),

please report it privately rather than opening a public issue.

**Contact:** Replace this line with the practice's security contact (email or private channel) before the repository is shared more widely.

We aim to acknowledge reports within 5 working days and to publish a corrected version within one errata cycle (see `CONTRIBUTING.md` for cadence).

## Out of scope

- Subjective disagreements with framework design choices — please open a regular issue or PR.
- Stylistic or formatting concerns — see `CONTRIBUTING.md`.
