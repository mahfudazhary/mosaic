# 02 — Capture

**Phase objective:** build the CADRE register.

**Typical duration:** 1–3 weeks (longer with deep compliance overlays or unfamiliar client estates).

## Inputs
- Engagement charter (from Frame).
- Selected compliance overlays — pre-populated R-restrictions.
- Stakeholder workshops, existing client documentation, regulatory references.

## Outputs
- [`cadre-register.md`](cadre-register.md) — baselined, signed off by named element owners.
- Workshop notes archived under `workshops/` (create as needed).

## Checklist before exiting Capture

- [ ] Every Demand has a testability criterion and MoSCoW priority.
- [ ] Every Restriction has a citation and `Waivable: Yes/No/Conditional`.
- [ ] Every Exposure has likelihood, impact, mitigation plan, and named owner.
- [ ] Every Assumption has a validation plan **and** a fallback.
- [ ] No entry has an empty Owner field.
- [ ] Compliance-overlay R-entries are loaded for every overlay in the charter.
- [ ] Baseline reviewed and signed by all element owners.
- [ ] Register version-tagged (e.g., `v1.0`) in revision history.

> **Capture quality is the single largest predictor of engagement quality.** Resist pressure to short-cut this phase.
